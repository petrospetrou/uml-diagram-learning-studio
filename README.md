# UML Diagram Learning Studio

An interactive Greek learning studio for building and exploring UML and system-model diagrams step by step.

**Repository:** [petrospetrou/uml-diagram-learning-studio](https://github.com/petrospetrou/uml-diagram-learning-studio)

## What it includes

- Eight guided diagram lessons using one consistent Campus Lost & Found scenario
- Walk-through, construction, and run/inspect modes
- Light and dark themes
- A complete scenario guide and a transfer exercise
- Greek explanations with essential English software-engineering terminology

## Run locally

Open `index.html` in a modern browser. No installation or internet connection is required.

## Educational scope

The diagrams are focused teaching examples. They illustrate modelling decisions; they do not replace requirements validation or performance testing.
